# AscendOS

AscendOS is a personal self-improvement command center, not a public startup product yet.

The app should feel like a polished personal RPG dashboard / command center, not a boring habit tracker or generic CRUD app.

Core question:
"What do I need to do today to become the version of myself I’m trying to become?"

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Lucide React
- Recharts
- Mock data/local state first
- Later: Supabase Postgres, Prisma, auth, AI API, GitHub API

## Priority tiers

Tier 1: Core non-negotiables
- Calories/protein
- Workout/cardio
- Deep work
- Project progress
- LeetCode/interview prep
- Sleep/basic hygiene

Tier 2: Strong enhancers
- Reading
- Meditation
- Gratitude journal
- Meal prep
- Water
- System design/ML/OS learning
- Language learning

Tier 3: Optional rituals
- Cold shower
- Oil pulling
- Mastic gum
- Lucid dreaming
- SATS
- Dream journal

Do not treat missing oil pulling as equally serious as missing protein, lifting, LeetCode, or deep work.

## Design vibe

- Dark, sleek, premium, futuristic
- Personal RPG / command center
- Subtle gradients
- Cards, badges, XP, streaks, levels
- Body = emerald/green
- Brain = blue/cyan
- Spirit = purple/violet
- Execution = amber/orange
- Mobile responsive, desktop-first is okay
- Avoid massive files
- Keep components reusable
- Use polished UI and tasteful animations
